Caesar Cipher

Classical shift cipher — shifts every letter by a fixed amount. Invented by Julius Caesar around 58 BC. With only 26 possible keys it is trivially broken by brute-force or frequency analysis.

Vigenère Cipher

Polyalphabetic substitution cipher using a repeating keyword. Each letter of the key applies a different Caesar shift. Stronger than Caesar but still broken by frequency analysis once the key length is determined.

Hash Functions

One-way deterministic functions — impossible to reverse. The same input always produces the same hash, but even a single character change produces a completely different output (avalanche effect). No key. No decryption.

ONE-WAY
MD5 Fast, broken for security. Used for file checksums only.
SHA-256 Secure. Used in TLS, Bitcoin, digital signatures, Git.
SHA-512 Maximum strength. Used in high-security applications.
