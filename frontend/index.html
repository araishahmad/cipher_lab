Caesar Cipher  WEAK

A classical substitution cipher that shifts each letter by a fixed number. Only 26 possible keys — trivially broken by brute-force or frequency analysis.

Vigenère Cipher  MEDIUM

Uses a keyword instead of a single shift. Each letter of the key applies a different shift — harder to brute-force than Caesar, but still vulnerable to frequency analysis once the key length is known.

AES Cipher  STRONG

AES-256 with PBKDF2 key derivation (200,000 rounds). Your password is never used directly — it is hashed 200,000 times with a random salt to produce a strong 256-bit key. Choose CBC or GCM mode below.

RSA Cipher  ASYMMETRIC

RSA uses two different keys — a public key to encrypt and a private key to decrypt. Anyone can encrypt with the public key, but only the private key holder can read the message. This is fundamentally different from AES where both sides share the same key.

Step 1 — Generate a key pair. Share your public key with anyone who wants to send you a message. Never share the private key.
Step 2 — Encrypt with the public key, decrypt with the private key.

Hash Functions

Hashing is one-way — you can hash a message but you cannot reverse a hash back to the original. The same input always produces the same hash. Even a tiny change in the input produces a completely different hash. Unlike encryption, there is no key and no decryption.

MD5 — 128-bit hash. Fast but broken for security purposes. Still used for checksums.

SHA-256 — 256-bit hash. Part of SHA-2 family. Used in TLS, Bitcoin, digital signatures.

SHA-512 — 512-bit hash. Stronger than SHA-256. Used where maximum hash strength is needed.
