Classical vs Modern Encryption — Encrypt, Decrypt & Attack Simulation

Caesar Cipher  WEAK

A classical substitution cipher that shifts each letter by a fixed number. Only 26 possible keys — trivially broken by brute-force.

Vigenère Cipher  MEDIUM

An improvement over Caesar that uses a keyword instead of a single shift. Each letter of the key applies a different shift — harder to brute-force, but still vulnerable to frequency analysis.

AES Cipher  STRONG

Advanced Encryption Standard with proper PBKDF2 key derivation. Your password is never used directly — it goes through 200,000 rounds of hashing to produce a strong 256-bit key. Choose between CBC and GCM mode below.

RSA Cipher  ASYMMETRIC

RSA uses two different keys — a public key to encrypt and a private key to decrypt. Anyone can encrypt with the public key, but only the private key holder can read the message. This is fundamentally different from AES where both sides share the same key.

Step 1 — Generate a key pair. Share the public key with anyone who needs to send you a message. Keep the private key secret.
Step 2 — Encrypt with the public key, decrypt with the private key.
